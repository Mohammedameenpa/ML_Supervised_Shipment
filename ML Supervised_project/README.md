# Shipment Delivery Prediction

## Project Overview

This project predicts whether a shipment will reach its destination on time using machine learning classification models.

## Dataset

The dataset contains shipment information such as:

* Warehouse Block
* Mode of Shipment
* Customer Care Calls
* Customer Rating
* Product Importance
* Gender
* Weight in Grams
* Cost of Product

Target Variable:

* Reached.on.Time_Y.N

## Project Workflow

1. Data Loading
2. Data Preprocessing
3. Train-Test Split
4. Model Training
5. Model Evaluation
6. Hyperparameter Tuning
7. Feature Importance Analysis
8. Model Saving

## Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* Gradient Boosting
* AdaBoost

## Evaluation Metric

* Accuracy
* Precision
* Recall
* F1 Score
